# WooriAIBook Website

우리AI북 메인 웹사이트입니다. 별도 빌드 과정 없이 `index.html`을 열면 확인할 수 있습니다.

## 이미지 구성

디자인 원본에서 분리한 이미지는 `assets/` 폴더에 있으며 각 섹션에 연결되어 있습니다.

- `hero.png`: 메인 히어로 배경
- `section_1_*`: 핵심 철학 이미지와 장식
- `section_2_*`: Ownabee 제품 및 기능 아이콘
- `section_3_*`: 미디어 영역 목업과 장식
- `section_4_*`: 작품 갤러리
- `logo.png`, `footer_*`, `language icon.png`: 헤더와 푸터

미디어 영역의 아이패드 화면 콘텐츠는 `.screen` 요소를 이미지, 동영상 또는 `iframe`으로 교체할 수 있습니다.
